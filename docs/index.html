Why developers prefer Fogoe

Eliminate tedious boilerplate with zero magic abstractions or vendor lock-in. Fogoe scaffolds clean codebases you actually own.

Pure On-Disk Templates

Unlike generators that embed massive strings into JavaScript source files, Fogoe preserves pristine template files directly on disk. Every template is linted, format-checked, and syntax-valid before it ever reaches your repository.

CLI Suite

Complete developer commands

Single-command project creation and modular code generation for daily workflow velocity.

fogoe
Launches interactive project scaffolding wizard in the current directory.
Interactive
fogoe create <name>
Scaffolds a new project inside a dedicated target directory.
Scaffold
fogoe g route <name>
Generates a typed API route in src/routes/ linked to its controller.
Generator
fogoe g controller <name>
Generates a framework-aware controller handler with request & response types.
Generator
fogoe g model <name>
Scaffolds a database model configured for MongoDB, PostgreSQL, SQLite, or Prisma.
Generator
fogoe add [plugin]
Installs and injects plugins into an existing Fogoe project (e.g. Redis, Zod, Stripe).
Plugin
fogoe status
Inspects current project runtime, module system, and Git repository state.
Diagnostics
