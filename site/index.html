CLI Commands

Manage project configurations, dependencies, and file scaffolding with zero friction.

Command Description
npx fogoe Starts the wizard to initialize a new backend in an empty folder.
fogoe init Initializes git, creates .gitignore, binds remote URL and pushes first commit.
fogoe status Queries config and directory state to display active runtime, databases, addons, and git flags.
fogoe generate <type> <name> Scaffolds a route, controller, or model matching framework, database, and language configurations.
fogoe update Upgrades project dependencies to their latest compatible releases using the detected package manager.

Add-on Plugins

Need additional utilities? Scaffold complete plugins inside existing projects.

Redis

Configures a pre-connected ioredis client config and env variable helpers.

fogoe add redis

Stripe

Sets up billing templates and imports the Stripe SDK configuration wrapper.

fogoe add stripe

Zod Validation

Scaffolds request validation frameworks and error-catching middleware.

fogoe add zod

Nodemailer

Generates transport configs, authentication keys, and email templates.

fogoe add mailer

Rate Limiter

Configures middleware limits to shield routes from denial-of-service traffic.

fogoe add ratelimit

Swagger Docs

Injects UI dashboards and configures routes to serve interactive Open-API specifications.

fogoe add swagger
